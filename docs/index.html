My Codex Plugin

A personal Codex plugin for reusable local skills. It starts with a plugin-check skill so you can confirm Codex has loaded the plugin.

Open Repository Install Locally 
Use plugin-check to verify my plugin is loaded.

Plugin Manifest

Defines the plugin metadata and points Codex at ./skills/.

Skill Bundle

Includes plugin-check, a small skill for install verification.

GitHub Pages

Ships with a Pages workflow so this site can deploy from docs/.

Install Locally

Register a local marketplace rooted at your home directory, then restart Codex.

1
Clone this repository into /Users/mikita/plugins/my-codex-plugin.
2
Point /Users/mikita/.agents/plugins/marketplace.json at ./plugins/my-codex-plugin.
3
Enable my-codex-plugin@local-plugins in /Users/mikita/.codex/config.toml.

Verify

After restarting Codex, ask it to use plugin-check. A successful response confirms that the plugin and skill were loaded.
