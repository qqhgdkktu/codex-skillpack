# Privacy Policy

Codex Skillpack is a local Codex plugin bundle. The wrapper repository does not
run a hosted service, does not include analytics, and does not intentionally
collect telemetry.

## What The Plugin Can Access

The plugin contains Agent Skills. When a skill is used, Codex may read or edit
workspace files, run commands, call configured MCP/app connectors, or use
external services if the active Codex session and user permissions allow it.

Data handling for those actions is governed by:

- the user's Codex/OpenAI configuration and account terms;
- the third-party service used by a skill or connector;
- the commands, tools, and credentials available in the local environment.

## Secrets And Credentials

Do not put API keys, tokens, passwords, private customer data, or regulated data
inside prompts, screenshots, logs, commits, issues, or generated examples unless
you have confirmed that doing so is appropriate for your environment.

## Third-Party Services

Some skills are designed for services such as GitHub, Figma, Sentry, Notion,
Linear, Vercel, Netlify, Cloudflare, Render, OpenAI, and documentation/search
providers. Those services may have their own privacy policies, data retention
rules, authentication scopes, and usage terms.
